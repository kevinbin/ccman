what it does

Built for people who keep many agents alive.

No Rust toolchain, no Node, no background daemon — just ccman.py and the Python you already have, managing as many Claude Code agents as you can open. One screen for every project, every running pane, every routine — with state you can trust, because it comes from the source, not the screen.

◷ routine◷

Routine sections

Scheduled-task runs are pulled out of their projects and grouped by name — each run tagged with its execution date on the right.

⑂ worktree⑂

Worktree-aware

Git worktrees render as ⑂ main · branch, with real paths resolved from session history so every one resumes in the right place.

⟳ live⟳

State from hooks

Responding, waiting, awaiting approval, idle — read from Claude Code hooks, never scraped. Sessions that need you blink.

✓ batch✓

Batch open

Mark any number of sessions with Space, then open them all into evenly-split tmux panes in one keystroke.

/ search/

Instant search

Fuzzy-filter across every project and session, jump between matches, and resume the one you want on Enter.

▌ tmux▤

Sidebar or solo

Lives as a pinned 20% tmux sidebar that re-splits panes evenly as you open sessions — or runs perfectly well standalone.

accurate status

Status from hooks, not guesswork.

Wire each Claude Code event at ccman hook once. Every session then writes its own state to disk — and survives a ccman restart.

~/.claude/settings.json
{
  "hooks": {
    "SessionStart":     "ccman hook",
    "UserPromptSubmit": "ccman hook",
    "PreToolUse":       "ccman hook",
    "PermissionRequest":"ccman hook",
    "Stop":             "ccman hook",
    "Notification":     "ccman hook",
    "SessionEnd":       "ccman hook"
  }
}

# each event pipes JSON to `ccman hook`, which writes
# ~/.config/ccman/state/<session_id>
get started

One command. No build step.

Pull the single script straight from GitHub onto your $PATH — no clone, no pip, no build:

mkdir -p ~/.local/bin && curl -fsSL https://raw.githubusercontent.com/kevinbin/ccman/master/ccman.py -o ~/.local/bin/ccman && chmod +x ~/.local/bin/ccman

Wire the hooks in ~/.claude/settings.json for live state — optional, but recommended.

Run ccman inside tmux for the sidebar, or anywhere to browse.

  • Python 3.8+ — stdlib only, no pip install
  • tmux — for sidebar mode & pane management
  • Claude Code CLI — the claude command
  • macOS / Linux — anywhere a terminal lives
